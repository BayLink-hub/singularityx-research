# SINGULARITYX · 零界演化

公开研究工作台：因子 AST 编辑、日频价格研究、策略回测、人工算子、事件研究、打新市值计算、复现流程与研究报告。

公开行情样本来自腾讯证券：固定 12 只股票及沪深300，2023-01-03 至 2024-12-31。另有经发布清单确认的120个work因子原代码、AST、辅助源码与原始汇总研究序列，以及本地数据目录/字段说明元数据。股票级原始行情、分钟/财务表、因子Parquet、账户与后台数据库不在仓库中。

因子库预置227条记录：原6条模板、work120和Alpha101全101定义。Alpha101文件夹逐式保留论文原式、代码块、AST、依赖和实现约定；当前公开样本满足39条公式的数据要求，39项真实研究按需读取，其余62项明确缺字段。全部用同一2024协议，保留负值与缺失，不宣称复现作者原始市场业绩。另7个通用研究案例同样来自真实计算。

人工算子共51项：32个可校验日频模板、19个真实手填财务/组合公式。支持版本编辑、软删除和恢复。原120代码可以修订并保存语法树，浏览器不执行任意Python；原版历史结果与新定义分开。原历史09:33研究费用为0、存在事后样本筛选，不能当作新撮合验证。

本版本由 GitHub Pages 托管，计算在浏览器执行；编辑、任务、报告保存在当前浏览器，清除站点数据会丢失，请使用导出。不同用户不会共享修改。既有 Python/SQLite 私有研究后台需独立服务器部署。

公开价格样本未复权，缺少成交额、财务公告、ST、涨跌停价、公司行动及退市结算数据；不代表全A历史股票池，也不是完整可交易收益验证。因子与策略结论均为探索性研究。AI流水线未配置大模型时采用有来源的公式模板和人工确认，不声称已由AI自动复现研报。

本地预览：Node 24、pnpm 11.25，执行 `pnpm install --frozen-lockfile`、`VITE_PUBLIC_MODE=true pnpm dev`。

发布：仓库 Settings → Pages → Source 选择 GitHub Actions；推送 main 后运行发布工作流。

源代码位于 `src/`，资源在 `public/research/`，历史序列按需读取。`pnpm test`验证安全语言、101覆盖及真实公开成交账本；`node scripts/seed_public_research.cjs`按固定协议重算公开案例。
